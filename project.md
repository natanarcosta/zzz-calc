Projeto é de uma calculadora de recursos para maximizar personagens e w-engines do jogo Zenless Zone Zero.
O objetivo é ter uma interface web em que o usuario inputa o quanto ele tem de recurso e o app mantém calculado e exibido o progresso em direção aos personagens desejados.
Um personagem tem uma classe e um elemento.
Classes: Armorer, Rupture, Attack, Stun, Anomaly, Support e Defense.
Elementos: Lumiflux, Wind, Physical, Fire, Ice, Electric e Ether.
Um personagem chega até o lvl 60.
Exp necessária para o nivel 1-60: 900.000 EXP 
Fonte de Exp: Investigator Logs ( Trainee: 100 EXP, Official: 600 EXP, Senior: 3.000 EXP)
Um personagem precisa de Certification Seals de sua classe para ascender.
4 Basic Seals, 32 Advanced Seals, 30 Top-Tier Seals.
Um personagem precisa de Dennies ( Dinheiro/Moeda do jogo ) para ascender. 3.700.000 Dennies em total.
Um personagem precisa de [Element] Chips para maximizar suas skills ativas. [25 Basic Chips], [75 Advanced Chips] e [250 Specialized Chips], ex: Basic Freeze Chip, Advanced Fire Chip, Specialized Wind Chip.
Um personagem precisa de 60 [Expert Challenge Materials] para maximizar sua skill passiva.
Um personagem também precisa de 9 [Boss Materials] para maximizar sua skill passiva.

Ao usar a interface o user inputará algo como, tem 10.000.000 Dennies, 750 Senior Investigator Logs, 30 Defense Top-Tier Seals, 45 Anomaly Top-Tier Seals, 300 Specialized Fire Chips, 80 Freeze Basic Chips etc.
O user também pode marcar quantos/quais personagens deseja acompanhar o progresso dos materiais, por ex: Miyabi ( personagem Anomaly/Ice ) + YiXuan ( personagem Rupture/Ether ) e assim por diante.
Interface deve ser leve e performática, porém intuitiva e moderna/bonita, já que é para público gamer.
O progresso pode ser salvo no localstorage de inicio, já que a aplicação será apenas frontend.
Imagino que a fonte de dados possa ficar em um json no projeto.
